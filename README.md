# Home SOC Lab

## Project Overview
This project demonstrates the design and implementation of a Home Security Operations Center (SOC) using open-source cybersecurity tools.

## Objective
- Build a Home SOC Lab
- Collect and analyze security logs
- Detect suspicious activities
- Investigate security incidents
- Document findings professionally

## Tools (Planned)
- Ubuntu Server
- Wazuh SIEM
- Kali Linux
- Windows
- Python
- Git & GitHub
